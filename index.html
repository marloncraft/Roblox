AULA 01 • LEADERSTATS

Barra de Pontos e Moedas (Leaderboard)

Cria a tabela no canto superior direito da tela do jogador para contar pontos, moedas ou fases concluídas.

Onde colocar no Roblox Studio: Crie um Script dentro de ServerScriptService.
Script Lua 
game.Players.PlayerAdded:Connect(function(player)
    -- Cria a pasta principal obrigatória chamada leaderstats
    local leaderstats = Instance.new("Folder")
    leaderstats.Name = "leaderstats"
    leaderstats.Parent = player

    -- Cria o contador de Pontos
    local pontos = Instance.new("IntValue")
    pontos.Name = "Pontos"
    pontos.Value = 0 -- Valor inicial
    pontos.Parent = leaderstats
end)
AULA 02 • INTERFACE (GUI)

Barra de Vida Personalizada na Tela

Faz uma barra vermelha/verde diminuir suavemente na tela conforme o personagem leva dano no jogo.

Onde colocar no Roblox Studio: Crie uma ScreenGui em StarterGui, adicione um Frame (Fundo) e dentro dele outro Frame (BarraVerde). Coloque um LocalScript dentro da BarraVerde.
LocalScript Lua 
local player = game.Players.LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()
local humanoid = character:WaitForChild("Humanoid")
local barraVida = script.Parent

-- Atualiza o tamanho da barra sempre que a vida mudar
humanoid.HealthChanged:Connect(function(vidaAtual)
    local porcentagem = vidaAtual / humanoid.MaxHealth
    barraVida:TweenSize(
        UDim2.new(porcentagem, 0, 1, 0),
        Enum.EasingDirection.Out,
        Enum.EasingStyle.Quad,
        0.2,
        true
    )
end)
AULA 03 • STRING E TEXTO NA TELA

Mostrar Nome do Personagem na Tela usando String

Usa concatenação de String (textos) para pegar o nome do jogador e exibir uma mensagem personalizada em um TextLabel.

Onde colocar no Roblox Studio: Crie uma ScreenGui em StarterGui, insira um TextLabel e coloque um LocalScript dentro dele.
LocalScript Lua 
local player = game.Players.LocalPlayer
local textoTela = script.Parent

-- Pega o nome de exibição (DisplayName) como String
local nomeJogador = tostring(player.DisplayName)

-- Junta (concatena) textos usando dois pontos (..)
textoTela.Text = "Jogador: " .. nomeJogador .. " | Nível 1"
